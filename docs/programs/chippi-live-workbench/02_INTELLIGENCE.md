# Chippi Live Workbench — Product Intelligence

Date: 2026-07-29
Program evidence type: intelligence

## Customer job

A real-estate team repeatedly converts messy business inputs into finished
working material:

- lead-source and agent production analysis;
- pipeline and conversion reviews;
- seller and listing presentations;
- comparable-property tables and CMAs;
- transaction checklists and status reports;
- brokerage forecasts and meeting packets.

The high-value product is not another answer in chat. It is an inspectable,
editable, exportable result that remains connected to the instruction and can
be revised without starting over.

## Ranked product opportunities

### 1. Chippi Live Workbench

Upload a production workbook, ask Chippi to clean and analyze it, then receive
an editable spreadsheet and narrative document beside the conversation. The
user can edit directly, ask for revisions, inspect sources, and export.

This is the strongest next move because it creates the visible output surface
that every later autonomous capability can use.

### 2. Chippi Computer Use

Let the realtor watch Chippi operate a public-web cloud browser, stop it, or
take over. Results should land in the Live Workbench as sourced tables and
documents.

### 3. Listing Launch Mission

Let one voice or chat instruction create coordinated workstreams for seller
context, comps, pricing, narrative, marketing, and appointment preparation.
The mission should assemble its deliverables in the Live Workbench.

## Counterevidence and exclusions

- A standalone “agent team room” does not solve the requested agent interaction
  or output problem and is not the primary product.
- More webhook, scheduler, or durability work is not product progress unless it
  directly blocks the selected Workbench journey.
- A terminal is an implementation capability, not the customer-facing result.
  Customers should see finished work, receipts, and controls.
- A read-only spreadsheet answer is insufficient; the result must remain
  editable and revisable.

## Decision impact

Commit Live Workbench as the primary vertical slice. Computer Use and larger
real-estate missions become sequenced follow-on capabilities after the artifact
contract and work surface exist.
